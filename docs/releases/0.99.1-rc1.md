## hdhr-mux 0.99.1-rc1 (release candidate)

A pre-release to try the published image and packages before 0.99.1. It will not move the `latest` image tag.

Changes since 0.99.0.

**Settings**
- **Settings apply while running.** The settings page has an **Apply** button, inactive until something changes. Everything that can change on the fly does (sharing options, guide and lineup timing, linger, client buffer, TTL, request logging, rescan mode, signal settle); the few settings read once at start (name, device ID, listen addresses, SSDP, devices) are marked "restart" and the page keeps saying they are waiting.
- **Restart is its own button and needs no supervisor**: the multiplexer shuts down cleanly and starts itself again in the same process, so it works in a container started without `--restart`. File descriptors are checked by a test.
- **0 means off** (instead of `-1s`) for `linger`, `guide.refresh`, `lineup.refresh` and `guide.start_delay`; the old negative values still work.
- New defaults: the guide is collected every hour (was 3 h) and guide passes leave tuners unlocked, so tvheadend or another DVR can take them.

**Channels DVR "sigerr"**
- New `signal_settle` (2 s, `0` = off): a tuner's symbol quality reads 0 for a moment after it locks and Channels DVR counts each such second as a signal error. For the first 2 s of a stream a zero is shown to clients as the tuner's last good reading; the activity page and `/metrics` keep the true figures. The status of a new stream is also refreshed every 200 ms for its first 8 s.

**ATSC 3.0**
- New `lineup.atsc3` (default on): `false` leaves ATSC 3.0 channels out of the lineup, playlist and guide (they still tune when asked for by number).
- The multiplexer's own scan (`lineup.scan_mode: own`) now says in the log when it could not scan ATSC 3.0 channels because no 3.0-capable tuner was free. The settings page describes the two rescan modes more clearly and has `lineup.scan_tuners_per_device`.

Everything else is as in 0.99.0. As before: no LICENSE file, arm images and packages cross-compiled but not run on hardware.
