## hdhr-mux 0.99.2

Changes since 0.99.0. (0.99.1 was only ever released as candidates; everything prepared for it is in here.)

**Channels tab (new, fourth tab)**
- Where each channel is received: one row per RF channel, with signal (strength / quality / symbols), hours of EPG ahead, and the name and program the multiplex gives it.
- Choices, saved in `channels.json`, applied at once: **Video** (which RF channels `/auto/` may tune; none = channel unavailable and left out of lineup, playlist, EPG), **First** (tuned first), **EPG** (which RF channel the guide comes from; default: the one that goes furthest ahead).
- `/auto/` order: ride an open session at any allowed place, then the first choice, then the others.
- EPG is stored per RF channel and never merged.
- Each guide pass also listens ~6 s to the broadcast RF channels (2-36, `us-bcast`) no lineup channel is on, to find stations carried on a second RF channel.

**Channel placement**
- Where a channel is on the air comes from the devices' `lineup.json?tuning`; the multiplex serves `?tuning` too. Streams only fill gaps (no more flipping between two RF channels).
- First guide pass on a new install finds where the channels are.

**Activity page**
- A tuner used by another application shows what it watches (the program it selected, or the programmes its PID filter takes; identical audio/video shown once), plus its address.
- EPG scans are labelled "EPG scan"; tuners sorted by viewer count.

**Discovery**
- Not discoverable until chosen (Settings, General / `-discoverable`).
- A hidden multiplexer still answers discovery sent to its own address, over TCP or UDP (Linux), so a DVR that adds it by IP works. Broadcasts and SSDP stay off. Not in setup mode.

**Sharing**
- `auto_join_direct`, `auto_join_other_locations`, `evict_scans`; UDP targets limited to private IPv4, TTL default 3 (max 8).

**Settings and running**
- Settings apply live (Apply button); restart in place; `0` means off; `-http` option; port 80 falls back to 8080; setup mode when no devices are found.
- New defaults: guide every hour, tuners unlocked for guide passes, diagnostics off.
- `signal_settle` (2 s) hides the zero symbol quality at tune (Channels DVR `sigerr`).
- `lineup.atsc3` hides ATSC 3.0 channels from lineup, playlist and EPG.
- This machine's CPU, memory, load, temperature and open files on the Activity page and in `/metrics`.

**Packaging**
- Packages: the binary and its systemd unit (`DynamicUser`); no config file, no `hdhrctl`.
- Upgrading from 0.99.0 or a candidate: `apt purge hdhr-mux`, `userdel hdhr-mux`, remove `/etc/hdhr-mux`, then install.

Still: no LICENSE file; arm packages cross-compiled, not run on hardware.
